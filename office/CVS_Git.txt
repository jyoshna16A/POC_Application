Maven build lifecycles :
------------------------
validate - Validate the project 
mvn validate

Compile - It will generate the java classes and checks the syntax error
mvn compile

Package- create the jar file
mvn package

Verify - need to check whether the package is valid or not 
mvn verify

install - create the jar file
mvn install

Maven Scope :
-------------
compile --> the dependency is needed for the compile, runtime and testing the code

provided --> the dependency is needed for compile time not at runtime 

runtime  --> the dependency is needed for runtime time

test  --> the dependency is needed for testing time

system --> The jar i didn't take from the Nexus or Maven, it is there in the local path, that jar need to add in the pom.xml, then will use the scope as system
